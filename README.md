# ⚡ EV Charging Analytics Dashboard

An interactive **EV Charging Analytics Dashboard** built in Microsoft Excel to analyze charging sessions, revenue, energy consumption, charger types, and session performance.

## 📊 Project Overview

This project analyzes EV charging station data to identify trends in revenue, charging activity, energy delivery, and charger performance.

The analysis was performed using **Excel, Pivot Tables, Pivot Charts, data cleaning, and interactive dashboard techniques**.

## 🎯 Project Objectives

- Analyze monthly revenue trends
- Measure total charging sessions
- Analyze total energy delivered
- Compare different charger types
- Analyze charging session status
- Identify revenue contribution by charger type
- Calculate average revenue per charging session
- Create an interactive dashboard for decision-making

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables

- Excel Charts

- Data Analysis
